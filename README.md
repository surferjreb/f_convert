## Problem

I have encounter many times where I need to convert a CSV file to a JSON format and vice versa.  There are
many tools on the web that can provide this function.  Not all tools output the correct format or if the app can be trusted with data.

---

## Description

This program will provide a simple user interface to convert standard csv files
to JSON and the reverse.
